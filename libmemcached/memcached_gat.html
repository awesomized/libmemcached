Get and update expiration atomically

SYNOPSIS

#include <libmemcached/memcached.h>

Compile and link with -lmemcached

char *memcached_gat(memcached_st *ptr, const char *key, size_t key_length, time_t expiration, size_t *value_length, uint32_t *flags, memcached_return_t *error)
Parameters:

  • ptr -- pointer to initialized memcached_st struct

  • key -- the key to fetch and touch

  • key_length -- the length of key without any terminating zero

  • expiration -- new expiration as a unix timestamp or as relative expiration time in seconds

  • value_length -- pointer filled with the length of the returned value, or NULL

  • flags -- pointer filled with the flags stored with the value, or NULL

  • error -- pointer filled with the return status, or NULL

Returns:

pointer to the retrieved value, or NULL on error or cache miss

char *memcached_gat_by_key(memcached_st *ptr, const char *group_key, size_t group_key_length, const char *key, size_t key_length, time_t expiration, size_t *value_length, uint32_t *flags, memcached_return_t *error)
Parameters:

  • ptr -- pointer to initialized memcached_st struct

  • group_key -- the key namespace used to select the server

  • group_key_length -- the length of group_key without any terminating zero

  • key -- the key to fetch and touch

  • key_length -- the length of key without any terminating zero

  • expiration -- new expiration as a unix timestamp or as relative expiration time in seconds

  • value_length -- pointer filled with the length of the returned value, or NULL

  • flags -- pointer filled with the flags stored with the value, or NULL

  • error -- pointer filled with the return status, or NULL

Returns:

pointer to the retrieved value, or NULL on error or cache miss

DESCRIPTION

memcached_gat() (Get And Touch) atomically fetches the value for a key and updates its expiration time in a single round trip to the server. It combines the semantics of memcached_get() and memcached_touch(): the current value is returned to the caller while the TTL is refreshed.

memcached_gat_by_key() works identically but accepts a group_key that controls which server the key is located on, enabling key partitioning.

Both functions support the text protocol (gat) and the binary protocol (GATK opcode).

The text protocol needs memcached 1.5.3 or later. Older servers answer ERROR, which memcached_gat() reports as MEMCACHED_NOTFOUND, so it looks like a miss.

The returned value must be released by the caller using free(3).

These functions are not supported when MEMCACHED_BEHAVIOR_USE_UDP is set; that behavior returns MEMCACHED_NOT_SUPPORTED.

RETURN VALUE

On success, a pointer to the retrieved value is returned and *error is set to MEMCACHED_SUCCESS. The caller must free this pointer with free(3).

NULL is returned when:

  • The key does not exist - *error is set to MEMCACHED_NOTFOUND.

  • A network or protocol error occurred - *error describes the failure.

Use memcached_strerror() to convert a memcached_return_t value to a human-readable string.
